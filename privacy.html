Какие данные хранит приложение

Пользоваться приложением можно без регистрации. В гостевом режиме прогресс, выбранные язык и тема сохраняются в локальном хранилище браузера на вашем устройстве.

Аккаунт и синхронизация

Если вы создаёте аккаунт, адрес электронной почты и данные для аутентификации обрабатывает Supabase Auth. Пароль не хранится приложением. После входа прогресс уроков и серия занятий передаются в базу Supabase для синхронизации с вашими устройствами. Доступ к строке прогресса ограничен аккаунтом с помощью Row Level Security.

Выполнение Python-кода

Код, который вы вводите в редактор, выполняется в браузере с помощью Pyodide. При первом запуске необходимые файлы среды загружаются с CDN jsDelivr. Не вводите в редактор пароли, ключи API или другие секреты.

Аналитика

Сейчас аналитика не включена по умолчанию. Если владелец сайта настроит счётчик Яндекс Метрики, он загрузится только после вашего согласия в приложении. Вы можете отказаться от аналитики.

Очистка данных

Вы можете удалить сохранённые прогресс и настройки, очистив данные сайта в настройках браузера. Удаление сайта также удалит его локальные данные и офлайн-кэш.

Изменения политики

Если изменится список обрабатываемых данных, сервисы или способы хранения, эта политика должна быть обновлена.

Этот текст описывает текущую работу приложения и не заменяет юридическую консультацию.
