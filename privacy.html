Какие данные хранит приложение

Пользоваться приложением можно без регистрации. В гостевом режиме прогресс, выбранные язык и тема сохраняются в локальном хранилище браузера на вашем устройстве.

Аккаунт и синхронизация

В серверном режиме адрес электронной почты, хеш пароля с индивидуальной солью, хеш резервного кода и прогресс хранятся в базе SQLite на сервере владельца сайта. Пароли и резервные коды не сохраняются в открытом виде. Для входа используется обязательный HttpOnly cookie сессии сроком до семи дней. Выход отзывает сессию на сервере. Почтовые сообщения в этом режиме не отправляются; почта используется как идентификатор, её владение не подтверждается. Для восстановления пароля сохраните резервный код, показанный после регистрации.

Если владелец переключит сайт в режим Supabase, адрес электронной почты и данные аутентификации будет обрабатывать Supabase Auth. В этом режиме доступны подтверждение почты и восстановление по письму. Прогресс передаётся в Supabase; доступ к нему ограничивается аккаунтом с помощью Row Level Security.

Выполнение Python-кода

Код, который вы вводите в редактор, выполняется в браузере с помощью Pyodide. При первом запуске необходимые файлы среды загружаются с CDN jsDelivr. Не вводите в редактор пароли, ключи API или другие секреты.

Аналитика

Шрифт главной страницы загружается с Google Fonts. При переходе на курсы сторонних школ действуют их собственные правила обработки данных. Наш аккаунт не передаётся этим школам.

Сейчас аналитика не включена по умолчанию. Если владелец сайта настроит счётчик Яндекс Метрики, он загрузится только после вашего согласия в приложении. Вы можете отказаться от аналитики.

Очистка данных

Очистка данных сайта в браузере удаляет локальные настройки, прогресс и офлайн-кэш, но не удаляет аккаунт и серверный прогресс. Для удаления серверного аккаунта обратитесь к владельцу установленного сервера. Автоматического удаления аккаунта в текущей версии нет.

Изменения политики

Если изменится список обрабатываемых данных, сервисы или способы хранения, эта политика должна быть обновлена.
