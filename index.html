Я совсем без опыта. У меня получится?+

Начните с Python: первый урок объясняет, как вывести текст на экран. Во встроенном курсе 90 уроков на трёх уровнях. Двигайтесь в своём темпе и возвращайтесь к темам, когда нужно.

Можно учиться бесплатно?+

Встроенный курс Python доступен бесплатно и без регистрации. В каталоге также есть ссылки на бесплатные курсы Code Basics и Coddy. Стоимость профессиональных программ других школ указана на их сайтах.

Зачем создавать аккаунт?+

Аккаунт позволяет синхронизировать прогресс Python между устройствами. Без входа прогресс хранится в этом браузере. Регистрация на «Код» не создаёт аккаунты на сайтах других школ.

Как устроен каталог школ?+

Это независимая подборка. Мы не представляем перечисленные школы. У каждой платформы свои программы, условия, оплата и регистрация. Материалы этих школ не копируются в наш тренажёр.

Можно заниматься с телефона?+

Да. Каталог, личный кабинет и тренажёр адаптированы для небольших экранов. Для больших программ удобнее компьютер, но читать теорию и выполнять первые задания можно с телефона.
